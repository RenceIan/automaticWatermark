# Automatic Watermark Generator

A static, browser-only watermark tool that runs on GitHub Pages. Upload multiple images, apply a text or logo watermark, and download the results as a ZIP file.

## Features
- Multiple image upload
- Text or logo watermark
- Position, size, and opacity controls
- Preview before download
- ZIP download for all processed images

## Run on GitHub Pages
1. Push this repo to GitHub.
2. Turn on GitHub Pages in the repository settings.
3. Select the branch that contains `index.html`.
4. Open the Pages URL shown by GitHub.

## Notes
- This version runs entirely in the browser.
- No XAMPP, PHP, or database is required.
- The older PHP files are no longer needed for GitHub Pages hosting.
