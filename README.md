Automatic Watermark Generator
=================================

Quick prototype to run under XAMPP (Windows) or any PHP web server.

Prerequisites
- PHP 7.4+ with GD extension enabled (Imagick optional).
- ZipArchive enabled (usually bundled with PHP).

Install / Deploy
1. Copy the `automaticWatermark` folder into your XAMPP `htdocs`.
2. (Optional) Add a TTF font to `fonts/arial.ttf` if you want nicer text watermarks.
3. Start Apache in XAMPP and open `http://localhost/automaticWatermark/`.

How it works
- Use the form to upload multiple images and choose watermark settings.
- Processed images will be returned as a ZIP download (or individual links).

Notes
- This is a minimal prototype. For production, add stronger validation, authentication, and cleanup.
